# CostLens media worker

Build from the repository root: `docker build -f worker/Dockerfile -t costlens-worker .`. The container uses Node 20, ffmpeg, a non-root UID 1000 and temporary per-job directories. In the managed cloud environment, preserve the configured proxy and provide its CA via `--secret id=proxy_ca,src=/etc/ssl/certs/ca-certificates.crt`; use `BUILDX_CONFIG=/tmp/costlens-buildx` if the user's home is read-only. The CA mount is not copied into the image. Normal deployments without a proxy can omit that secret (Node may warn that the optional extra certificate path is absent).

For local TypeScript work: `npm --prefix worker ci --cache /workspace/.npm-cache`, then `npm --prefix worker run build`. Start with `npm --prefix worker start` after setting the values in `.env.example` through your environment manager. Node does not automatically load this file. The app and worker must share WORKER_SECRET; generate one with `openssl rand -hex 32`, keep it out of Git, and save it in both services. APP_URL is the CostLens origin, for example `https://your-costlens.vercel.app`, not Supabase. OPENAI_API_KEY is for Whisper; no Gemini or Supabase service key is placed in the worker.

Deploy this Dockerfile on an always-on Render web service, Docker context `.` and health path `/health`. Configure APP_URL, WORKER_SECRET and OPENAI_API_KEY; Render supplies PORT. In the app configure WORKER_URL to the resulting worker HTTPS origin, and the same WORKER_SECRET. Budget for two concurrent jobs and roughly 2 GB temporary disk for the maximum file sizes. The worker polls the database-backed app interface every 30 seconds, so queued jobs survive a missed trigger or worker restart. A processing lease stale for 30 minutes becomes failed and is cleaned up; files are not blindly re-transcribed after a crash.

The worker never receives database credentials. The server signs a bucket-specific, job-specific download URL after atomically claiming the job. Callbacks are HMAC-authenticated over purpose, job ID, timestamp and a hash of the body. The `/jobs` trigger signs purpose + ID + timestamp and rejects timestamps older than five minutes or over one minute in the future. Atomic claims and the in-process active set reject duplicate work. Max concurrency is two; remaining work stays queued.

ffprobe runs with an explicit allow-listed demuxer, file/pipe-only protocols, bounded output and a timeout. It validates the actual media streams, codecs, dimensions and duration. Audio is converted to 16 kHz mono PCM and split at ten minutes (under Whisper's 25 MB chunk cap). Transcription uses verbose JSON segment timestamps with chunk offsets. Video sends at most 40 evenly distributed frames (at least ten-second spacing) and up to 20 scene-change frames, capped at 60 total; a 30-minute video cannot both sample every ten seconds and obey a 60-frame cap, so coverage is spread across its duration. Frames are bounded JPEGs and callback bodies stay below the Vercel body limit.

Users explicitly consent to sending their recording to the speech provider. When masking is on, transcripts are redacted by the app's shared AI gateway and video frames are omitted. When masking is off, frames use that gateway's guarded media input. Gemini calls, quotas, cache validation and usage auditing remain only in `lib/ai/client.ts`; the worker never calls Gemini directly. No transcript or extracted frame is stored in jobs: only validated CostRows and the file hash remain.

Temporary downloads, chunks and frames are removed after processing or failure. The private original stays available during review for timestamp playback and is removed after an idempotent, transactional commit. Failed and abandoned recordings expire within 24 hours; the worker's poll performs cleanup retries, including successfully committed jobs whose first deletion failed. The app cleans recordings before a project deletion, and refuses the project deletion if cleanup fails. Hosting the worker continuously is required for these cleanup sweeps.

The two media fixtures are synthetic, reproducible speech and a narrated spreadsheet animation. `node scripts/create-media-fixtures.mjs` regenerates them with ffmpeg's flite filter and Sharp. They are not represented as a human voice recording.
